# Denver Rail

Which Denver corridors are worth rebuilding in a modern mode, using the historic Denver Tramway network as a corridor map and comparing it with today's RTD ridership, planned rapid transit, and Census commute flows. Planning is tracked with OpenSpec in `openspec/` (run `openspec` commands from this folder).
